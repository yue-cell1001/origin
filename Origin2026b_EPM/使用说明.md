# Origin 2026b 复现准备包

本包是绘图数据、样式参数和参考图，不是已完成的 Origin 工程。没有在 Origin 内运行或验证附带导入脚本。原始附件保持不变。

## 使用方法

1. 解压到固定目录。保留原有 Origin 项目，在新项目中导入。
2. 在 Origin 2026b 自带的 Python 环境运行 import_into_origin.py。可以在其 FIGURES 中只保留 [2]，先导入图2。脚本使用 originpro 和 pandas；若运行环境缺少模块，请先确认运行的是 Origin 内置 Python。无需在当前 Linux 云环境安装 originpro。
3. 导入脚本只建立数据工作簿，不创建图形。也可直接将 CSV 导入工作表。
4. 依据下述说明创建原生图层，保存为 .opju。图2和图8先做样板，其余按共同样式展开。
5. 按 reference 中最终 PNG 的尺寸、比例逐图导出对照。最终外观尚未在 Origin 中验证，不能视为已复现。

## 文件含义

- original_data：附件 CSV 数据的副本，含原始模型预测、误差和汇总。
- reference：附件中最终单图 PNG，以及图1原图。总览和旧图号对照表不作为最终尺寸依据。
- Fig02 至 Fig11：每图数据和 style.json。
- layerN_lineXX.csv：线的真实坐标，列 X/Y，三维线另有 Z。
- layerN_scatterXX.csv：散点的真实坐标，图2下排包含固定随机抖动后的坐标，无需重新随机生成。
- layerN_polygonXX.csv：密度轮廓等多边形。按 Path 分组并保留 Vertex 顺序绘制封闭填充曲线，Code 是 Matplotlib 路径码，不是 Origin 数据列角色。导入后需按路径分组；不得把多个轮廓直接连成一条线。
- style.json：原图程序应用最终样式后的轴限、刻度、图层位置、颜色、字号、线宽、标记、透明度等。含三维视角与气泡面积信息。
- Fig07/bubble_mapping.csv：原生三维气泡图所需列。marker_area_pt2 是原程序标记面积参数，marker_diameter_pt 是平方根换算；Origin 的符号尺寸定义需实测校准，不能把面积直接当直径。
- Fig08/*_bias_grid.csv：三种模型的规则网格。首行为交通流量系数，首列为 CAV 百分比，网格内部是有符号偏差秒数。需正确设置矩阵 X/Y 坐标。

## 共用样式与布局

主模型配色：BPR #555555，Fu #D88C00，EPM #269E94。具体图中透明度与配色以各 style.json 为准。
原图在此云环境使用包内字体：西文字体 Paper Times、中文 Reconstructed SimSun 与后备字体。Windows 常见 Times New Roman/宋体可以使用，但字宽可能不同，需逐一检查换行和对齐。原字体文件在原始压缩包 fonts 内。
JSON 线宽和字号单位为 pt，散点 sizes_pt_squared 为面积参数。
position_normalized 为原始画布中的 [left,bottom,width,height]。若 Origin 用从页面顶部起算的位置，Top=1-bottom-height，均乘100转成百分比；它们不是最终裁切 PNG 内的归一化位置。
canvas_mm 是未裁切画布尺寸。原程序使用 tight bounding box 导出，不能直接把画布尺寸当最终图片尺寸。最终尺寸详见本包 reference_dimensions.csv。
一些文本包含原程序坐标变换的描述，需区分轴内数据坐标、轴比例坐标和页面坐标；不能把所有文字坐标当作数据坐标使用。

## 各图重建方法

图2：8个原生二维图层，上排4个预测-观测散点，下排4个误差分布；导入半小提琴的实际轮廓，以填充多边形叠加散点、四分位线和中位数。不要使用 Origin 默认核密度重新估计。三模型×四实验各95样本。
图3：4个图层，观测值及三模型样本序列。保留原始排序与连线，X范围0至100。
图4：2个图层，四实验分组散点、1:1参考线、统计表；表格放在散点上方，单元格背景不透明。
图5：3个图层，残差密度轮廓+散点+四分位数、MAE/RMSE哑铃图、绝对误差阶梯累计分布；阶梯坐标已展开，按给定坐标连线，勿再次按阶梯规则重复展开。
图6：3个图层的单因素折线图，基准参考线与空心点一并保留。
图7：1个三维图层和色标。X交通流量系数，Y=CAV百分比，Z观测平均行程时间，颜色EPM MAE，点大小为相对Fu的MAE降幅归一化映射。色图viridis，保留负降幅。原程序最终仰角24度、方位角-130度，但这两个数不等于Origin的旋转角，应以参考图对齐。连接线及气泡图例也需还原。
图8：同一三维图层叠加三组规则网格曲面和节点，透明度0.60，不平滑、不重新拟合。有符号偏差决定高度；三组曲面按统一 abs(bias) 范围映射白色到各模型颜色，不要让每个曲面独立自动缩放颜色。原图最终视角为仰角27度、方位角-132度：调用 clean3d 时覆盖了此前的24/-130。还需零偏差参考面。
图9：1个散点图层，三模型+1:1线，同范围等比例坐标，不随意改为从0起点。
图10：2个图层，MAE与RMSE，X=CAV百分比，含80%刻度。三模型的线型和标记按JSON设置。
图11：单图层135样本；保留分组顺序，每27个样本分界，背景色带、场景文字与上置图例需手动还原。背景色带属于补丁对象，本包JSON没有完整导出其样式，应对照原源码 all_series.py 与参考图。
图1：只有1267×628位图，缺框架图可编辑源文件，不属于本包数据复现范围。原生重建需要源文件或重新绘制图形对象。

## 验收

数据核验与外观核验分开：先核对样本数、范围、误差和曲面网格，再按相同最终尺寸导出。叠加参考图检查图层边界、坐标刻度、字体、线宽、散点大小、图例、色标和三维视角。Origin与Matplotlib渲染机制不同，逐像素一致尚不能保证。

## 已验证与未验证

已验证：图2至图11的原程序能够在云环境构建图形对象并提取27个图层（含色标轴）；CSV可读取，图2的抖动散点和密度轮廓已提取，图7含30组参数，图8每模型为6×5规则网格。
未验证：Origin导入脚本运行、原生图页构建、.opju保存与重开、Origin最终导出与外观匹配。此处不提供伪装的.opju文件。
